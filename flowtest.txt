Flow test:
Sales -> Upload month-paired JSON (["YYYY-MM", qty, ...], ascending, closed months, max 60) -> Import Preview shows oldest-to-latest coverage, missing months block, zeros warn, existing-range conflicts need overwrite tick -> Confirm Import writes one Completed row per month -> View Month Sales for the imported data.

Forecasting -> Type -> Generate Forecast -> Display Predicted demand for next full month. Needs 12 minimum months, uses 36 maximum months of complete monthly sales. Current month is never charted until it closes (table shows one text-only "(in progress)" placeholder row instead of a number).

Production -> Create prod Batch -> Ongoing -> Update Batch Status to Completed (no delete; guarded against double-Completed). Completed batch goes to inventory with prod_id = batch_id and bumps the total ledger. Production staff + admin only.

Inventory -> View current stock, total produced, total released this month, & production today. Production inflow vs Stock-Out bars (both Stock Added top-ups and deducts counted). Can Deduct total stock with 'Edit Total Stock', 'Add Total Stock' to increase it. Both write a history leg (Stock Deducted / Stock Added, ref TOTAL).

Recent inventory movement -> summary of last 3 days with activity (inflow = production touches + Stock Added top-ups, outflow = Completed flips + deducts). Balance reconstructed backward from current stock (approximation). Net + shows Production, net - shows Stock-Out.

Dashboard -> Total/current vermicast stock with default label of KG (hover converts on desktop, tap on mobile; 1 Sack = 50 KG). Active batches = Ongoing production count. Completed Today. Safety Stock card + goal line (admin/inventory_staff can Save Goal). Inventory Trend plots the stock_daily ledger (one recorded row/day, snaps on every ledger write + dashboard visit; last known carries forward, pre-history renders as gap). Goal-based banners: green at/above goal, orange under goal, red at <= 5 Sacks, danger text at zero.

Users -> Admin only. One active account per role (admin, inventory_staff, production_staff); deactivated accounts free their slot. Add User needs password + confirm match; password standard is 8+ chars with 1 letter + 1 number, common passwords rejected. Admin Email card (email + confirm) feeds password reset. Admin Panel: verify current password, then set new + confirm (5-min window, Cancel clears).

History -> Per-user for non-admins (own username only, admin rows never leak); admin sees all. User column shows "username - role".

Reports -> Tabs: Production (totals + bar chart + records + PDF), Inventory (beginning/added/out, ending banner, movement table), Stock-Out (outflow only + PDF), Forecast (Holt's DES + CSV/PDF).

Login -> Forgot Password link shows only when online. Send Code (5s wait) mails the admin email; code is hashed, single-use, 10-min expiry, max 5 attempts (wrong codes AND mismatches burn attempts, then lock), IP-bound. New password must differ. Last-resort link appears only after a send attempt and notifies the hardcoded backup inbox (human acts manually; system never self-deletes). New password fields have show/hide toggles; Close button after every result.
